#  DnDAIe5 — D&D 5e AI Master Engine

Полнофункциональное веб-приложение для настольных ролевых игр по системе **D&D 5e** с искусственным интеллектом в роли Мастера Подземелий (Dungeon Master) на базе **Google Gemini 3.7 Flash**, **LM Studio (локально)**, **OpenRouter**, **DeepSeek** и **Next.js 15 (App Router)**.

Поддерживает как одиночное прохождение, так и архитектурную базу для **кооперативного режима (Party / Co-op)**.

---

##  Возможности

-  **Широкая поддержка ИИ-моделей**:
  -  **Google Gemini API**: `gemini-3.7-flash` с поддержкой мышления (Thinking mode), мгновенным стримингом и точным следованием правилам SRD 5e.
  -  **LM Studio / Локальные LLM**: прямое подключение к локальному серверу (`http://127.0.0.1:1234/v1`) — 100% приватность без интернета и затрат.
  -  **OpenRouter Free Tier**: NVIDIA Nemotron 3 Super (`nvidia/nemotron-3-super-120b-a12b:free`), DeepSeek V3/R1, Qwen 2.5 и др.
  -  **Официальные API**: DeepSeek, Groq Llama 3.3 70B, OpenAI-compatible эндпоинты.
-  **Нейросетевая озвучка (Edge-TTS & Web Speech)**:
  - Реалистичные голоса рассказчика (Microsoft Edge TTS: Дмитрий, Светлана и др.) с генерацией аудиопотока в реальном времени.
  - Синхронизация субтитров и интерактивное управление озвучкой сообщений.
-  **Интерактивный лист персонажа D&D 5e**:
  - Расчёт характеристик ($STR, DEX, CON, INT, WIS, CHA$), спасбросков, пассивной внимательности, инициативы.
  - Автоматический трекинг $HP$, временных $HP$, $AC$ и динамического инвентаря с весом и золотом.
-  **Броски кубиков ($d20, d12, d10, d8, d6, d4, d100$)**:
  - Бросков с процедурным звуковым генератором Web Audio API.
  - Структурированные запросы проверок навыков ($DC$, преимущество/помеха, автоматический учёт бонусов).
-  **Журнал квестов, карты и заметки**:
  - Автоматическое и ручное ведение дневника путешествия, истории локаций и NPC.
  - Экспорт и импорт сохранений кампании в JSON.
-  **Roadmap**:
  -  Мультиплеерный / Кооперативный режим партий (Shared Party Session & Co-op Lobby).

##  Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка окружения (Опционально)
Создайте `.env.local` в корне проекта при необходимости:
```env
GEMINI_API_KEY=your_gemini_api_key_here
# или
OPENROUTER_API_KEY=sk-or-v1-...
```
> *Все ключи и URL локального LM Studio также можно настроить прямо в интерфейсе через меню **⚙️ Настройки**.*

### 3. Запуск сервера разработки
```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.
